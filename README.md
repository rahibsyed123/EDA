# Exploratory Data Analysis on Titanic Dataset

## Project Overview
This project was completed as part of the CodeAlpha Data Analytics Internship. The objective of this task was to perform Exploratory Data Analysis (EDA) on the Titanic dataset to understand the structure, trends, and important insights from the data.

---

## Objectives
- Understand the dataset structure
- Analyze missing values
- Explore statistical summaries
- Identify patterns and relationships
- Generate insights using visualizations

---

## Dataset Used
Titanic Dataset

---

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

---

## Analysis Performed
- Data loading and inspection
- Missing value analysis
- Statistical summary generation
- Survival analysis
- Passenger class analysis
- Gender distribution analysis
- Correlation heatmap visualization

---

## Files Included
- EDA.ipynb
- titanic.csv
- README.md

---

## Conclusion
The analysis helped identify important trends in passenger survival, gender distribution, and class distribution using Python-based data analysis techniques.
